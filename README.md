# System Design Roadmap (2026)

A step-by-step plan to learn system design from scratch and pass high-level design (HLD), low-level design (LLD) / machine-coding, and AI-era design interviews. It uses **free resources only**.

**Read the roadmap:** [system-design-roadmap-2026.md](system-design-roadmap-2026.md)

## What's inside

- **13 phases (0–12)**, from networking and database basics through distributed systems, APIs, reliability, estimation, the interview framework, LLD / machine coding, AI/ML/GenAI design, advanced topics, and mock interviews
- **A placement test** to help you decide which phases to skip
- **Three tracks:** Fast (8 weeks), Core (16 weeks, the default) and Deep (24 weeks)
- **40 practice problems in 4 tiers**, from foundations to AI-era designs such as RAG pipelines and LLM gateways
- **A week-by-week schedule** sized for about 10–12 hours a week, plus one buffer week
- **Cheat sheets:** latency numbers, availability nines, powers of two, database selection, caching strategies, consistency models, key trade-offs and capacity rules of thumb
- **A progress tracker, a mock-interview scorecard and a final readiness checklist**
- **A full index of free resources:** guides, YouTube channels, blogs, papers, LLD material and mock-interview platforms

## Who it's for

| You are | Start at |
|---|---|
| Student / fresher (0–1 yr) | Phase 0 |
| SDE-1 moving to SDE-2 (1–4 yrs) | Phase 1 |
| SDE-2 moving to Senior/Staff (4+ yrs) | Phase 1 (fast review) |

The roadmap also covers the machine-coding rounds that many Indian product companies run.

## Getting started

1. Take the [placement test](system-design-roadmap-2026.md#placement-test-what-can-you-skip) (about 10 minutes).
2. Pick a [track](system-design-roadmap-2026.md#three-tracks) and follow [the 16-week schedule](system-design-roadmap-2026.md#the-16-week-schedule) or one of its variants.
3. Use the learning loop for every topic: **learn it → see it in a real system → use it in a problem → explain it out loud in 2 minutes**.
4. Record your progress in the [progress tracker](system-design-roadmap-2026.md#progress-tracker).
